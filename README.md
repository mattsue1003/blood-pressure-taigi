# 血壓機講啥物？做伙看懂健康數字（台語）

長者線上社區課程的互動網頁簡報（單一 HTML，免安裝）。講師：蔡欣潔 護理師。

- **25 頁、約 60 分鐘**：先聽大家講（常見說法）→ 圈叉暖身 → 血壓機三個數字 → 血壓紅綠燈 → 為什麼會高（改得動／改不動）→ 不控制會怎樣 → 紙劇場小電影①「阿雪姨量血壓」→ 看圖找錯（放大特寫）→ 五句口訣姿勢 → 722 紀錄 → 分類題 → 偏高怎麼辦（排序）→ 紙劇場小電影②「阿坤伯看醫生」→ 用藥快問快答 → 四筆帳／六件事／台灣給您的靠山 → 大魔王找錯 → 填空帶回去 → 承諾牆 → 結語。

## 使用方式
- ← → 或空白鍵換頁；`N` 講師提示（電影頁會逐幕顯示台語辯士台詞）；`F` 全螢幕；`T` 搶答計時。
- 「目錄」可跳頁；講師手冊：網址後面加 `#notes`，可用手機或第二螢幕對照。
- 「台灣給您的靠山」那頁，課前請換成授課鄉鎮的衛生所、安心血壓站與據點資訊。
