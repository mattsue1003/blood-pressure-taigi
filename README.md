# 血壓機講啥物？做伙看懂健康數字（台語）

長者線上社區課程的互動網頁簡報（單一 HTML，免安裝）。

- **前半段（講課＋問答）**：據點相借問、圈叉題、血壓機三個數字、血壓紅綠燈、兩段「默片電影院」電影法（老師當辯士，不用 YouTube）、看圖找錯、五句口訣姿勢示範、722 紀錄、用藥與看診提問。
- **後半段（坐姿運動，免道具）**：舉手深呼吸、踩油門、坐著踏步、出拳喊聲、「血壓三兄弟」腦力遊戲、坐姿踢腳、扶椅坐到站、慢呼吸收操。

## 使用方式
- ← → 或空白鍵換頁；`N` 講師提示（電影頁會逐幕顯示台語辯士台詞）；`F` 全螢幕；`T` 搶答計時。
- 「目錄」可跳頁；講師手冊：網址後面加 `#notes`，可用手機或第二螢幕對照。
- 「我可以得到的」那頁，課前請換成授課鄉鎮的衛生所、安心血壓站與據點資訊。

## 手機觀看
手機上會自動切換成「可上下捲動」模式：左右滑動換頁、上下滑動看完整內容。

## 插圖
`img/` 內的插圖（封面、兩張默片風格海報、運動、線上課程）由 ChatGPT 生成，已壓縮成網頁用尺寸。
